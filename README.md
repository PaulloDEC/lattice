# Lattice is an enhanced PC port of Apogee's “Hocus Pocus”, built on top of a full decompilation of the game. #

To play you’ll only need one file from the **full version** of Hocus Pocus: “HOCUS.DAT”, which should be approximately 6mb in size. Drop that file in the same location as the new .EXE from Github and you’ll be good to go. I’ve tested using the GOG version, but as long as you’re using the full version, i.e. not shareware, it shouldn’t vary.

All the expected features are present, including:

- Choice of aspect ratios: original 4:3 or new 16:9
- Choice of classic HUD or no HUD
- High framerate support with interpolation for smooth movement and scrolling
- Support for modern controllers with button rebinding
- In-game menus for an authentic feel

Possible future inclusions:

- Slimline HUD for a larger play area
- Expanded artwork for widescreen, in select cases

Based on my testing the project is currently in a good state, but I haven’t played every level of all four episodes, so it’s entirely possible there’s edge-case bugs hanging around. If you come across any, I'd be grateful for a bug report in the Issues section.
